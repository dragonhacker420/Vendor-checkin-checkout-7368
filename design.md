# RouteStamp Design

**Direction:** Night-shift logistics. Asphalt-dark surfaces, high-vis safety yellow, hazard-stripe and dock-ticket motifs. Feels like a tool used in a parking lot at 5am.

## Color
- Asphalt `#111315` (bg), Tarmac `#1A1D20` (surface), Curb `#2A2E33` (lines)
- Hi-Vis `#E6FF2B` (primary accent, CTAs, active states)
- Paper `#F2F0E9` (text), Concrete `#8C9196` (muted)
- Status: On site `#3DDC84`, Pending `#FFB020`, Overstay `#FF4D3D`

## Type
- Display: Archivo (800–900, expanded width, uppercase, tight tracking)
- Body: Archivo 400/500
- Data: IBM Plex Mono (timestamps, timers, distances, IDs)

## Patterns
- Hazard stripes (45° yellow/black) as section dividers
- "Ticket" cards with perforated edges + mono metadata
- Phone mockups for mobile flow; dark dashboard panels for manager
- Square-ish radius (4–8px), 1px Curb borders, no soft shadows
- One staggered load reveal; live timers tick
